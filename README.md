# **College Admission Form**

## **Project Description**  
The **College Admission Form** is a web-based form designed to streamline the admission process for colleges.  
It includes various fields that users can fill out to provide their details for admission, such as:  
- **Name**  
- **Category**  
- **Nationality**  
- **Education**  
- **Anti-Ragging Form Number**  

This project simplifies the admission process by collecting all necessary details in an organized and structured format.

---

## **Technologies Used**  
- **Frontend**: HTML and CSS  

---

## **Features**  
- **Comprehensive Fields**:  
  - Includes all essential fields required for college admissions.  

- **User-Friendly Design**:  
  - Clean and simple design to ensure ease of use for applicants.  

- **Responsive Layout**:  
  - Styled using CSS to ensure compatibility with various devices.
